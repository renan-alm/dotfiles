# PDF Extraction Reference

## Libraries

| Library | Use Case |
|---------|----------|
| `pdfplumber` | Text and table extraction |
| `pypdf` | Form filling, merging, splitting |
| `pdf2image` | Convert pages to images |
| `Pillow` | Image manipulation |

## Installation

```bash
pip install pdfplumber pypdf pdf2image Pillow
```
